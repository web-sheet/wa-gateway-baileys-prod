Dokumentasi API
WhatsApp Gateway

Integrasikan WhatsApp Gateway Anda dengan mudah menggunakan REST API. Mendukung pengiriman pesan teks, gambar, dokumen, webhook realtime, serta queue system otomatis untuk menjaga keamanan nomor WhatsApp.

Version

v1.0

Delay Queue

4s

Authentication

Semua request API wajib menyertakan API Key pada header request.

Header Type Description
Content-Type String application/json
x-api-key String API Key unik milik akun Anda
POST

/send

Digunakan untuk mengirim pesan teks ke nomor pribadi maupun grup WhatsApp. Mendukung single target dan multi target sekaligus.

Request Body 

{
  "number": "628123456789",
  "message": "Halo, ini contoh pesan teks otomatis."
}

Success Response 

{
  "success": true,
  "message": "Pesan berhasil dimasukkan ke antrian",
  "targets": ["628123456789@s.whatsapp.net"],
  "queueRemaining": 1
}
POST

/send-image

Mengirim gambar dengan caption. Mendukung multiple image broadcast, AppSheet URL, dan Google Drive direct link.

Request Body 

{
  "number": ["628123456789"],
  "images": [
    {
      "url": "https://domain.com/image.jpg",
      "caption": "Foto Produk"
    }
  ]
}
ℹ️ Pastikan file gambar dapat diakses publik dan tidak membutuhkan login. Untuk Google Drive gunakan format direct link.
POST

/send-document

Digunakan untuk mengirim file dokumen seperti PDF, Excel, Word, maupun file lainnya ke nomor WhatsApp maupun grup.

Request Body 

{
  "number": "628123456789",
  "documentUrl": "https://domain.com/file.pdf",
  "fileName": "invoice.pdf",
  "caption": "Silakan unduh file berikut"
}
⚠️ Maksimal ukuran file dokumen adalah 10 MB agar queue server tetap stabil.
POST

/send-status

Endpoint ini digunakan untuk menerbitkan cerita atau info promosi langsung ke WhatsApp Story (Status) nomor WhatsApp yang terhubung. Sistem secara otomatis mendukung penerbitan berformat teks murni ataupun gambar ber-caption.

Request Body (Format Gambar / Text) 

{
  "title": "Promo Internal Senin",
  "message": "Yuk buruan dibeli diskon up to 50% hanya hari ini!",
  "mediaUrl": "/uploads/promo-senin.jpg", 
  "repeatType": "once"
}

Success Response 

{
  "success": true,
  "message": "Jadwal status berhasil disimpan dan didaftarkan ke sistem cron.",
  "broadcastId": "64f1bc9d231a4c8d10223f12",
  "targetJid": "status@broadcast"
}

🎯 Catatan Sistem Status Internal:

  • Sistem ini menembak JID khusus internal WhatsApp secara global yaitu status@broadcast.
  • Parameter mediaUrl bersifat opsional. Jika dikosongkan, status otomatis terbit sebagai status teks biasa.
  • Setiap cron yang didaftarkan disimpan ke RAM Server dengan skema pengaman khusus, sehingga jika jadwal dihapus lewat UI Dashboard, pemicu otomatis mati total tanpa bocor memori.
